# Project Context: Personal Portfolio

## 🌟 Overview
This project is a high-end personal portfolio designed to showcase senior-level engineering capabilities. It transcends a simple static site by incorporating complex architectural visualizations, interactive diagrams, and a sophisticated industrial aesthetic.

## 🎯 Strategic Intent
The portfolio aims to demonstrate:
1.  **Frontend Mastery**: React 19, Framer Motion, and high-performance UI patterns.
2.  **Engineering Rigor**: Clear separation of data and UI, spec-driven design, and detailed project deep-dives.
3.  **Visual Identity**: A "Sophisticated Industrial" aesthetic that communicates precision, technical depth, and modern design sensibilities.

## 🛠️ Core Technology Stack
- **Framework**: React 19 + TypeScript (Vite)
- **Styling**: Tailwind CSS v4 + Custom Vanilla CSS for advanced effects.
- **Motion**: Framer Motion for sophisticated animations.
- **Localization**: i18next for multi-language support (English/Spanish).
- **Data**: Static JSON-driven content (`src/data/projects.json`).

## 👥 Audience
- **Primary**: Hiring managers and technical leads looking for high-level engineering talent.
- **Secondary**: Open-source contributors and other developers seeking inspiration for complex UI/UX implementations.

## 🏗️ Key Architectural Features
- **Spec-Driven Design**: All major features or changes are preceded by a specification document.
- **Docs as Code**: Documentation and specifications live alongside the code, managed via Git.
- **Component-Based UI**: Modular, reusable UI elements and sections.
- **Interactive Deep-Dives**: Project modals that explain the *Why* and *How* through diagrams and structured narratives.
